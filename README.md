# Atividade de POO 6 - Manipulação de Vetores e Ordenação em Java

Este repositório contém a resolução prática dos exercícios da atividade **POO - 6**, focados em manipulação de vetores (arrays), geração de números aleatórios e ordenação manual de dados em **Java**.

---

## 📌 Exercícios Desenvolvidos

### 1. Cálculo de Notas da Turma (`Exercício 1`)
- Criação de um vetor do tipo `double` com 5 posições.
- Leitura das notas informadas pelo usuário via `Scanner`.
- Processamento para encontrar:
  - Todas as notas digitadas;
  - A maior nota;
  - A menor nota;
  - A média geral da turma.

### 2. Ordenação de Vetor Aleatório (`Exercício 2`)
- Geração de um vetor com tamanho aleatório entre **5 e 20**.
- Preenchimento do vetor com números inteiros aleatórios entre **0 e 9** usando a classe `Random`.
- Exibição do vetor original.
- **Ordenação manual em ordem crescente** utilizando o algoritmo **Bubble Sort** (sem o uso do método `Arrays.sort()`).

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **Linguagem:** Java
- **Entrada e Saída:** `java.util.Scanner`
- **Valores Aleatórios:** `java.util.Random`
- **Exibição de Arrays:** `java.util.Arrays`
- **Estruturas de Repetição:** Laços `for`
- **Algoritmo de Ordenação:** Bubble Sort (troca direta de elementos com variável auxiliar `aux`)
